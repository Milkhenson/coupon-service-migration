## Ключевые параметры

- Пик нагрузки: 2000 активаций/сек, 400 гашений/сек, 1000 входящих запросов/сек на гашение.
- Расчетные суточные объемы: ~60 млн активаций, ~12 млн гашений (при допущении, что пик занимает 35% суток).
- Рост таблиц: COUPON ~9,17 млрд строк/год (среднее), COUPON_EVENT ~30,3 млрд строк/год (среднее).
- SLA гашения: p95 <= 7 сек, p99 <= 8 сек (синхронно); активация допускает асинхронность (брокер).
- Миграция - near-zero: параллельная работа двух БД, окно простоя 5-10 минут ночью 01:00-02:00 МСК.
- Статусы купона: A (активен), D (погашен), E (ошибка, обратим через поддержку).
- Сервис не только проверяет ключи касс, но и генерирует/выдает их 25-го числа ночью, на следующий месяц.

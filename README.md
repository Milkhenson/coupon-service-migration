# Сервис купонов - миграция Oracle -> PostgreSQL

Спецификация требований (SRS) и план работ по выносу сервиса купонов из монолита
в отдельный микросервис с миграцией БД Oracle -> PostgreSQL. Интеграции
проектируются заново.

## Ключевые параметры

- Пик нагрузки: 2000 активаций/сек, 400 гашений/сек, 1000 входящих запросов/сек на гашение.
- Гашение - синхронно, SLA 5–10 сек; активация допускает асинхронность (брокер).
- Миграция - near-zero: параллельная работа двух БД, окно простоя 5-10 мин ночью 01:00-02:00 МСК.
- Статусы купона: A (активен), D (погашен), E (ошибка, обратим через поддержку).
- Сервис не только проверяет ключи касс, но и генерирует/выдаёт их 25-го числа ночью, на следующий месяц.
